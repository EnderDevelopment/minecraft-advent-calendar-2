# Calendar

The Calendar plugin is a Minecraft plugin designed to create an interactive Christmas calendar for your server. It features a user-friendly GUI with 24 slots, each representing a day of the calendar. Players can open the calendar using the `/calendar` command and interact with the items inside. The plugin is resource-efficient and supports customization through a comprehensive configuration file. It is compatible with Paper 1.21.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Paper server.
3. Restart or reload your server to load the plugin.

## Use

1. Open the calendar by typing `/calendar` in the chat.
2. Click on the chests to open the calendar items.
3. Use the barrier item to close the calendar.
